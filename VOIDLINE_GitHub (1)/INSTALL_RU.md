# Обновление текстового оформления

Картинки шапки и игры остались прежними.

1. В репозитории style-beep/style-beep нажми Add file → Upload files.
2. Перетащи README.md и папку assets из этого архива в область загрузки.
3. Нажми Commit changes.

README заменится. В assets добавятся три SVG с типографикой. Старые неиспользуемые файлы удалять не обязательно.

SVG содержат статичный текст без скриптов, внешних шрифтов и анимации. Изображения масштабируются по ширине. Для чтения без графики предусмотрена раскрывающаяся текстовая версия. Общий интерфейс GitHub и его шрифт не меняются.
